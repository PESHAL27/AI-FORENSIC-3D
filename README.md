# AI FORENSIC 3D

> **From Evidence to Possibilities.**
> Reconstruct real-world scenes, explore possible scenarios, and interact with alternative outcomes inside an intelligent 3D environment.

## 🚀 Features

- **Volumetric 3D Crime Scene Reconstruction**: Full 3D room model built with Three.js featuring physical architectural elements, furniture, evidence markers, and measurement vectors.
- **360° Interactive Orbit & Controls**: Rotate, pan, zoom, and reset views with ease.
- **Forensic Evidence Markers**: Interactive raycast markers (01–04) with real-time ballistics and kinematics inspection cards.
- **Cyber Holographic Aesthetics**: Sleek dark mode, chamfered neon action buttons, cyber-terrain particle waves, and top-tier forensic HUD styling.

## 🛠️ Tech Stack

- **React 19** + **TypeScript**
- **Vite**
- **Three.js** + OrbitControls
- **Lucide React**

## 🏃 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
